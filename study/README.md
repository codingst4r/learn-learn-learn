# Practice kit

Same study guides and commands as your Codespace, set up for practicing on your laptop.

## How to practice a lesson

1. Ask Claude Code to make the file, like "make lesson6.py", or type `/start`.
2. Type the lesson's example in yourself, then run it: `py lesson6.py`. GUI windows pop up right on your screen.
3. Do the "Try it yourself" in a new file, like `lesson6_try.py`.
4. Stuck? `/hint`. Think you got it? `/check`.
5. Before you stop: `/leftoff`.

Keep `breezypythongui.py` in this folder, or GUI programs can't import it.

## Reading the guides

Open `study/chapter9.md` or `study/chapter10.md`, then press `Ctrl+K` then `V` to see it next to your code.

## Your commands

| Type | When | What happens |
|---|---|---|
| `/start` | Sitting down to practice | Where you left off + one small next step |
| `/lesson radio buttons` | A concept doesn't make sense | Quick mini-lesson |
| `/hint` | Stuck on a try-it | The next hint only |
| `/check` | You think it works | What's right, what's wrong and why |
| `/quiz` | You have 5 minutes | 3 quick questions |
| `/leftoff` | You're about to stop | Saves where you are to `study/progress.md` |

## One thing to know

This folder's `progress.md` is separate from the one in your Codespace. This one tracks practice and that one tracks homework.
