---
name: start
description: Start a practice session. Use when Mike says he's starting, coming back to practice, or asks what he should do next.
---

Help Mike get back into practice fast. Restarting after a break is the hardest part for him, so make the first step small and clear.

1. Read `study/progress.md`.
2. In three short lines, tell him:
   - where he left off (use his own note if there is one)
   - what's done so far
   - **one** suggested next step that takes 10 to 20 minutes: usually the next lesson, or the try-it from the last one
3. If it's been a few days since the last session log entry, say that's normal and that's why the step is small.
4. Offer to make the practice file for it (like `lesson6.py`), empty, so he can type the example himself.
5. Ask: "Want to do that, or something else?"

Keep the whole reply short. No lecture.
